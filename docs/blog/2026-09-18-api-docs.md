We are happy to announce that Gancio v2.0 now has a nice [API documentation](/dev/api) which you can find in the Hacking > API section.

All data endpoints are available with its description, needed parameters and responses you will get. It is specified if authentication is required or not, as well.

Moreover, you can enter your input data and get on the fly the request (with `cURL`, `Javascript`, `PHP` and `Python`).  
In addition, you can test it directly at [demo.gancio.org](https://demo.gancio.org) clicking `Try it out` button.

![API example](api_example.png "A test to get all events tagged `Genova 2001` from the demo instance using the new documentation")

Technically, to generate this documentation we are using [swagger-jsdoc](https://www.npmjs.com/package/swagger-jsdoc) and [vitepress-openapi](https://vitepress-openapi.vercel.app/).

You are invited [to use and test it](/dev/api), and if you want to collaborate adding more examples, improving the documentation or fixing a bug, don't hesitate to collaborate.
