It’s [been quite a while](/changelog#_2-0-0-alpha-1-2025-08-5), but we’ve finally reached a point where we can wrap things up and release a beta.
We think it’s a good starting point for setting up new instances, but not quite ready for updating existing ones yet. Of course, if you want to give it a try, that’s great, let us know how it goes :smile:

"OK, but how do I try it out?"

The easiest way is to use the [demo](https://demo.gancio.org) instance. For those who want to compare, we’ve kept the old demo instance at [https://legacy.gancio.org](https://legacy.gancio.org).

If you’d rather install a new instance, you can choose to install it via [Docker](/install/docker), [Podman](/install/podman), or directly via [npm](/install/debian).

I’d like to thank all the contributors, this release wouldn’t have been possible without your invaluable help, from translations (we’re now in over 40 languages) to countless suggestions, testing, bug reports, and chats, but especially the code contributions: especially [@germanfr](https://social.linux.pizza/@germanfr), who made most of the improvements you’ll appreciate and which we’ll tell you about soon, and also @tina, @monica, and @sim6, who are giving me a big hand in bringing some structure and order to my mess, thanks also to [nlnet](https://nlnet.nl)’s contribution.
