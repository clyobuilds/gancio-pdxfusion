# Install


## Pre-requisites
- a Linux machine with <strong>root access</strong> (a VPS with 500MB of RAM and a cpu should be enough :stuck_out_tongue_winking_eye:)
- a domain name or subdomain (eg. events.mydomain.org, [subpath are not supported yet](https://framagit.org/les/gancio/-/issues/430))
- a mail account to deliver emails
